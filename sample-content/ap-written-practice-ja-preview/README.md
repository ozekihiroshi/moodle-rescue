# 応用情報技術者試験 過去問題学習 — 公開体験版

LessonMarkで作成したMarkdown教材の利用体験を、Moodleのゲスト利用者へ公開するための小さなコースです。

コース名には「公開体験版（問1・問2）」と明記し、完全版と区別します。

## 目的

- 問1（情報セキュリティ）と問2（経営戦略）だけをゲストへ公開する
- 公式問題、作業答案、折りたたみ式の公式解答例・解説を同じページで学ぶ流れを示す
- LessonMarkによるMarkdown教材制作、画像管理、自己確認ブロックの利便性を紹介する
- 問1〜問11の完全版は、ログイン・受講登録が必要な別コースとして運用する

## 配布物

distributionディレクトリに、ユーザー情報を含まないMoodleコースバックアップを収録しています。

- 短縮名：IPA-AP-WRITTEN-JA-PREVIEW
- LessonMark活動：3件（案内、問1、問2）
- 公式問題ページ画像：10枚
- Quiz活動：0件
- ゲストアクセス：バックアップにパスワードなし設定を収録（復元後に管理者が明示的に有効化）
- 必要なプラグイン：LessonMark 0.2系

## ソースとの関係
