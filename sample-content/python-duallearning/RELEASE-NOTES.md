# Python Dual Learning 0.1.0-alpha.1

First complete four-course distribution: English/Japanese, self-paced/teacher-guided,
Chapters 0–6. English remains the canonical curriculum.

- Markdown lessons rendered through LessonMark and structured with Dual Learning.
- 23 learning checks (230 questions), 8 assignments and 32 Lab links per course.
- Guided editions include preparation, review and chapter help forums.
- User-free backups exclude local test submissions, feedback and hidden legacy activities.
- Portable internal activity links and independent question stamps support restoration
  of all four editions on one site.
- LTI credentials are intentionally removed; administrators must connect their Lab.

See README for plugin requirements, restoration instructions and alpha limitations.
Existing non-Dual Learning course packages are retained.
