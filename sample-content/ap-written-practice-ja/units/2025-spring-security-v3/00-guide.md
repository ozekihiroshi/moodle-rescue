# この原文・解答解説版の進め方

この版では、IPA公式問題冊子の問1〜問11を、問ごとにページ画像のまま表示します。本文、図、表、下線、空欄、解答群、字数指定を教材側で要約・言い換えません。

## 令和7年度春期 午後 — 収録分野

| 問 | 主な分野 | 題材 |
|---:|---|---|
| 問1 | 情報セキュリティ | サイバー攻撃への対策 |
| 問2 | 経営戦略 | 中期事業計画と多角化戦略 |
| 問3 | アルゴリズム・プログラミング | スライドパズルと幅優先探索 |
| 問4 | システムアーキテクチャ・クラウド | BEMSのクラウド移行 |
| 問5 | ネットワーク | 社内LANの障害対応 |
| 問6 | データベース | 販売管理データベースの設計とSQL |
| 問7 | 組込み・ソフトウェア設計 | 電動キックボード共有システムの設計 |
| 問8 | システム開発・エラーハンドリング | CRMシステムのエラーハンドリング |
| 問9 | プロジェクトマネジメント | CCPMによるプロジェクト管理 |
| 問10 | サービスマネジメント | クラウド時代の容量・能力管理 |
| 問11 | システム監査 | 勤務管理システムの監査 |

問1は必須問題です。問2〜問11は試験では選択問題ですが、この教材では全問を収録しています。これから学ぶ分野と題材を確認し、関心のある問から始められます。

各問では、次の順序で学びます。

1. その問の公式問題ページを順に読む
2. 同じLessonMarkページ内で、設問ごとに自分の答案を入力する
3. 各答案欄の直下にある「公式解答例と解説を確認する」を開く
4. 正誤だけでなく、根拠となる本文、図、表へ戻る
5. 最後の「問題文を深く読む」で、事例に含まれる設計や判断を考える

解答欄の内容は、このブラウザ内だけに保存される作業用答案です。Moodleへ提出・採点されません。公式解答例と解説は設問直下で折りたたまれており、自分で考えた後でも、解答を見ながら学ぶ場合でも、任意のタイミングで開けます。

午後試験では、問1が必須で、問2〜問11から選択して解答します。この教材は学習用として全問を収録しています。試験時の選択数にかかわらず、関心のある分野から学べます。

## 読むときの視点

最初から正解の語句だけを探さず、次の四つを区別します。

- **事実**：問題文、図、表に明記されていること
- **関係**：複数の事実、処理、構成要素がどうつながるか
- **判断**：担当者が何を根拠に設計や対策を選んだか
- **制約**：字数、解答群、単位、桁数、既存仕様など、答案を絞る条件

解説を読んだ後で公式問題へ戻り、答えを支える一文や表の項目を指せれば、一回目の学習は完了です。
