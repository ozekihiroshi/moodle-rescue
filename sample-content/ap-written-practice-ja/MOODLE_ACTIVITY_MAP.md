各問の活動内は、次の順序で統一します。

1. 公式問題冊子の該当ページ画像
2. 設問別の作業答案欄
3. 各答案欄の直下に置く、閉じた状態の公式解答例・解説
4. 公式問題を設計・判断の材料として読み直す短い考察

学習者は一つのLessonMarkページ内で問題、答案、解答解説を扱います。作業答案は現在のブラウザ内だけに保存され、Moodle Quizの試行、評点、提出、活動完了にはなりません。

### V3の役割分担

| 要素 | 担当 |
|---|---|
| 公式問題の忠実な表示 | IPA公式ページ画像 + Moodle File API |
| ページ・設問・公式解答の対応 | `course-manifest-v3.json` + `question-catalog-v3.json` |
| 教材本文、設問、解説 | LessonMark Markdown |
| 一時的な作業答案 | LessonMark自己確認ブロック + ブラウザlocalStorage |
| 採点・受験履歴・教師確認 | この教材では扱わない。必要時は別のMoodle Quizまたは課題を設計する |
