# 第1章・第2章 教材構造実装報告（v38）

## 完了範囲

第3章v37で確立した教材構造を、学習段階に合わせて第1章・第2章へ適用した。対象は英語版・日本語版の各9レッスン、合計18ページと18冊のNotebookである。

章末プロジェクト1.7と2.4については、課題文、データ、スターター、関数契約、確認プログラム、提出条件を変更していない。各レッスンからプロジェクトへ何が渡されるかを明確にした。

## 共通構造

各レッスンは次の順序になった。

1. 導入
2. このレッスンの到達目標
3. 必須・補足・統合練習を示す学習経路
4. 4～7個の番号付き学習項目
5. 各項目に属する小見出し、本文、コード例、確認
6. 統合練習
7. まとめ
8. 次のレッスンまたは章末プロジェクトへの接続

Moodleの活動名をページ全体の表題とし、本文内部ではh2を学習上の大きな段階、h3をその下位概念に使用した。h4は使用していない。

- 1.2.4 統合練習：小さなモデルの状態を追跡する

### 1.3 基本データ型・型変換・算術

- 1.3.1 基本的なスカラー型を区別する
- 1.3.2 数値演算子と明示した順序で計算する
- 1.3.3 必要な型へ変換し、値を検証する
- 1.3.4 統合練習：割合を計算して確かめる

### 1.4 文字列・入力・書式付き出力

- 1.4.1 文字列を作り、調べ、変換する

- 1.4.3 入力を受け取り、計算用の型へ変換する
- 1.4.4 意味の分かる書式付き出力を作る
- 1.4.5 単純な区切り文字付きテキストを読む
- 1.4.6 統合練習：入力・計算・報告をつなぐ

### 1.5 条件による判断

- 1.5.1 ブール値を生む比較条件を作る

- 1.5.6 短絡評価を安全確認に使う
- 1.5.7 統合練習：業務ルールを実装して検証する

### 1.6 ループによる繰り返し

- 1.6.1 forとrangeで既知の値を繰り返し処理する
- 1.6.2 合計と条件付き件数を作る
- 1.6.3 最大・最小などの値と位置を追跡する
- 1.6.4 一回の処理またはループ全体を制御する

- 1.6.7 統合練習：値の並びを処理して報告する

## 第2章の構造

### 2.1 リスト・辞書・レコード

- 2.1.1 リストで順序のある値を保持し、変更する

### 2.2 関数・エラー・テスト

- 2.2.1 入力と出力が明確な関数を定義する
