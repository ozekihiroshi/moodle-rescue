## Situation

A community learning centre lends shared equipment. At opening time staff receive an inventory CSV and a CSV containing the day’s requests. They need a program that processes requests in order, refuses impossible state changes, and leaves an auditable closing inventory and a result for every request.

## Program to complete

Open `projects/equipment-lending/equipment_lending.py` in Python Lab and complete its TODOs. Do not start from an empty file.

1.  Build five `EquipmentItem` objects from inventory.
2.  Pass six requests to the desk in file order.
3.  Change state only for accepted requests and retain each rejection reason.
4.  Save closing inventory and request results to separate CSV files.
5.  Display summary counts.

## Supplied source files

`data/equipment_inventory.csv` is the opening inventory. `data/lending_requests.csv` is the day’s work. Do not edit or overwrite either source.

Opening inventory: `data/equipment_inventory.csv`

```

E003,Network Practice Kit,Networking,

E005,Portable Speaker,Audio,
```

Requests to process: `data/lending_requests.csv`

```

R001,LOAN,E001,M014

R003,RETURN,E004,

R005,RETURN,E003,

```

## Rules

- Reject empty required values, duplicate IDs, double lending, return of an available item, unknown IDs, and unknown actions.
- A rejected request must preserve item state and processing must continue.
- Save result rows in request order and inventory rows in item-ID order.
- Do not rename published classes, functions, parameters, constants, or output fields.

## Expected result for the supplied data

```
EQUIPMENT LENDING REPORT
REQUESTS: 6
ACCEPTED: 3
REJECTED: 3
TOTAL ITEMS: 5
AVAILABLE ITEMS: 2
LOANED ITEMS: 3
```

R001, R003, and R004 are accepted. R002, R005, and R006 are rejected. Final borrowers are E001=M014, E002=M021, E003 empty, E004 empty, and E005=M018.

## Implementation route

1.  `EquipmentItem`: construction, state, transitions, row conversion.
2.  `LendingDesk`: collection, search, delegation, summary, inventory saving.
3.  `load_inventory` and `process_requests`.
4.  `save_results` and `run_project`.
