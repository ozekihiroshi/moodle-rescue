## Teacher model

```
registered = 40
weekly_attendance = [31, 33, 30, 34]
total = sum(weekly_attendance)
mean = total / len(weekly_attendance)
rate = mean / registered * 100
if rate < 75:
    status = "support"
elif rate < 85:
    status = "watch"
else:
    status = "on track"
print(round(rate, 1), status)
```

Accept an explicit loop instead of sum(). Require tests such as 74.9, 75, 84.9, and 85. Ask the learner to change registered or one weekly value and predict the direction before running.
