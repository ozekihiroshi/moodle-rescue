# Python Foundations — self-paced Markdown edition

English adaptation of the canonical English Python course for LessonMark and `format_duallearning` self-paced mode. Chapters 0–6 are installed in local course 44 for review.

See [implementation and verification status](../../../docs/python-english-self-paced-markdown-progress.md).

`source-manifest.json` and chapter manifests record local source/copy activity mappings. `page-*.md` contains exported source material; only pages marked visible in chapter manifests are installed as learner-facing LessonMark activities. Hidden legacy exports are provenance, not additional lessons to publish.

`review-*.md` supplements the first nine lessons. The dedicated weekly-support guide uses this course's assignment rather than the original course submission bridge. Programs, datasets and automated project checker contracts remain canonical.

This directory is an authoring source, not a standalone production course installer. Local IDs and URLs must not be treated as production configuration. Distribution requires a verified user-free Moodle backup and site-specific Python Lab LTI setup.
