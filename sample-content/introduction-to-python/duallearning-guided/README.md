# Python Foundations — Teacher-guided Markdown edition

Chapters 0–6, based on the canonical English content through the English self-paced Markdown edition. The Japanese edition supplies the established guided workflow, not a replacement source for English lesson content.

Each of 23 units has preparation, a shared lesson, Python Lab, independent review and a knowledge check. Seven chapter forums provide optional help. Eight assignment destinations retain the original deliverable contracts; Chapter 3 requires one of A/B/C, not all three.

Preparation and review completion are learner confirmations, not grades. Teachers configure their actual teaching schedule and assignment deadlines. Lab files are shared per learner, while Moodle submissions and grades belong to this course.
