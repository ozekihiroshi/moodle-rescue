# レッスン5.2：誤解を生まない比較

## 導入

中央診療所は患者数が多いため待ち時間の総負担が最大でありながら、小規模な別の時間帯では一人の患者がより長く待っていることがあります。両方とも正しい観察です。誤解を生まない比較では、問い、分子、分母、粒度、軸、集団の大きさを明示します。

## このレッスンを終えると

- 総負担、一人当たりの経験、影響を受けた割合を区別できる。
- 互換性のある合計値から全体の率を計算できる。
- 集団の大きさ、欠測、順序、丸め前の順位を保持できる。
- 軸または集計単位が印象を変える場合を発見できる。

> **必須経路：**5.2.1～5.2.5　統合練習：5.2.6

## 5.2.1 三種類の問いを分ける

| 指標 | 計算 | 答える問い |
|---|---|---|
| 待ち時間合計 | 分数を合計 | 総負担が最大だった場所はどこか |
| 一人当たり平均待ち時間 | 合計分数÷患者数 | 記録上の典型的な待ち時間が最長だった場所はどこか |
| 60分超割合 | 60分超患者数÷患者数×100 | 長時間待つことが最も多かった場所はどこか |

一つを別の指標の代わりとして説明しません。人員配置には総負担が必要でも、特定業務の調査には診療所・時間帯別の経験が必要な場合があります。

## 5.2.2 互換性のある値を合計してから割る

6週間をまとめるなら、患者数と待ち時間をそれぞれ合計してから割ります。週別平均の単純平均では、患者の少ない週と多い週が同じ重みになります。

```python
service = records.groupby(
    ["clinic_id", "clinic_name", "time_slot"], as_index=False
).agg(
    patients_seen=("patients_seen", "sum"),
    total_wait_minutes=("total_wait_minutes", "sum"),
    over_60_minutes=("over_60_minutes", "sum"),
    source_records=("week", "size"),
)
service["average_wait_minutes"] = (
    service["total_wait_minutes"] / service["patients_seen"]
)
service["over_60_rate"] = (
    service["over_60_minutes"] / service["patients_seen"] * 100
)
```

## 5.2.3 比較の粒度と集団の大きさを示す

診療所別と診療所・時間帯別の表は、別の問いへ答えます。粒度の異なる行を同じ順位へ混ぜません。平均や割合には患者数を添えます。210人の平均48分と、2人の平均48分では判断の文脈が違います。

## 5.2.4 軸と順序で差を誇張しない

棒の長さを比べる図は0から始めます。46分と48分の棒を45分から始めると、2分の差が巨大に見えます。折れ線の細かな変化を読むために狭い軸を使う場合は、その範囲を示し、絶対差も書きます。

順位は丸め前の値で決め、表示するときだけ丸めます。同順位は安定したIDで終えると、毎回同じ出力になります。

```python
ranked = service.sort_values(
    ["average_wait_minutes", "over_60_rate", "clinic_id", "time_slot"],
    ascending=[False, False, True, True],
)
```

## 5.2.5 欠測と部分集団の違いを残す

欠測は0ではありません。週が欠けているなら、周囲の点をそのまま結ばず、欠けたことを示して理由を調べます。また、全体値が部分集団の逆方向の変化を隠すことがあります。判断対象が全患者、一診療所、一時間帯のどれかを確認し、その粒度の表を表示します。

## 5.2.6 統合練習

診療所別の60分超患者数合計と、診療所・時間帯別の60分超割合の二つの順位を作ります。患者数も表示し、先頭が異なっても両計算が正しい理由を二文で説明してください。

## まとめ

- 総量、一人当たり、割合は、別の業務上の問いへ答えます。
- 互換性のある件数を合計してから率を求めます。
- 粒度、件数、軸、順序、丸め、欠測、部分集団が比較へ影響します。
