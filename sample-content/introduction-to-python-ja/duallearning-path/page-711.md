## 教師用参考資料：発展プロジェクト

必須のデータセットや唯一の正解はありません。良い提出物では、次の流れを確認できます。

1.  結果を手作業で検証できる小さなテストデータ
2.  `usecols`、`dtype`、または理由を説明できるチャンクサイズの明示
3.  処理行、欠損行、不正行、除外行の件数
4.  複数のチャンクに現れる同じグループの合計が正しく統合されていること
5.  手作業でも確認できる大きさの最終集計
6.  数値で裏付けられた主張、限界、根拠のない因果関係を避けた説明

### 口頭で変更を求める例

- チャンクサイズを変更してください。結果が同じになるべき理由は何ですか。
- テストデータへ不正な行を一つ追加してください。どこで数えられますか。
- 抽出条件のしきい値を変更し、変化の方向を予想してください。
- 採用しなかった、または変更したAIの提案を一つ説明してください。

単なる行数の多さを評価しません。正しさ、検証、必要性に見合ったデータ利用、学習者が成果物を説明・変更できることを評価します。
