## 1.3.1 基本的なスカラー型を区別する

    print(34, type(34))
    print(82.5, type(82.5))
    print("34", type("34"))
    print(True, type(True))
    print(None, type(None))

| 型         | 例              | 表すもの                   |
|------------|-----------------|----------------------------|
| `int`      | `34`            | 小数部分を持たない整数     |
| `float`    | `82.5`          | 小数を含む数値             |
| `str`      | `"North"`       | 文字の並び                 |
| `bool`     | `True`、`False` | 真か偽か                   |
| `NoneType` | `None`          | 値がないことを示す特別な値 |

`type()`は、今ある値の型を確かめます。`None`は0や空文字列ではなく、「値がない」ことを表す別の値です。真偽値は条件分岐で詳しく扱いますが、この段階では数値や文字列とは異なる型だと理解します。

**確認:** この項目の中心となる値・処理・結果を、自分の言葉で区別して説明できますか。

## 1.3.2 数値演算子と明示した順序で計算する

### 数値を処理する七つの算術演算子

数値型には、加算`+`、減算`-`、乗算`*`、除算`/`、切り下げ除算`//`、余り`%`、べき乗`**`を使えます。

| 式        | 結果   | 用途                           |
|-----------|--------|--------------------------------|
| `10 + 3`  | 13     | 合計を求める                   |
| `10 - 3`  | 7      | 差を求める                     |
| `10 * 3`  | 30     | 同じ量のまとまりを求める       |
| `10 / 3`  | 3.333… | 割合や平均を求める             |
| `10 // 3` | 3      | 満杯になるまとまり数を求める   |
| `10 % 3`  | 1      | まとまりに入らない余りを求める |
| `10 ** 2` | 100    | べき乗を求める                 |

Python 3では、整数同士でも`/`の結果は通常`float`です。`//`は単に小数部分を切り捨てる説明だけでは不十分で、負数も含めて小さい整数側へ丸めます。このコースの箱詰め例では正数を使い、「満杯になる箱数」として読みます。

### 優先順位と括弧で、計算の意味を示す

べき乗、乗算・除算、加算・減算の順に評価されます。`2 + 3 * 4`は14、`(2 + 3) * 4`は20です。優先順位を覚えるだけでなく、人が式の意味を読み間違えないよう括弧を使います。

    books = 53
    per_box = 12
    full_boxes = books // per_box
    remaining_books = books % per_box
    print("満杯の箱:", full_boxes)
    print("余る冊数:", remaining_books)

53冊を12冊ずつ分けると、満杯の箱は4箱、余りは5冊です。全冊を収める箱数は5箱なので、`//`の結果をそのまま「必要な箱数」と呼んではいけません。演算結果が仕事上のどの量を表すかを確認します。

## 1.3.3 必要な型へ変換し、値を検証する

### 型を暗黙に期待せず、明示的に変換する

CSVや入力フォームから受け取った数字は、文字列になっていることがあります。文字列の`"36"`へ数値の4を直接加えることはできません。整数が必要なら`int()`、小数を含む数値なら`float()`、表示用の文字列なら`str()`を使います。

    learners_text = "36"
    learners = int(learners_text)
    print(learners + 4)

    cost_text = "487.50"
    cost = float(cost_text)
    print(cost, type(cost))

変換できない内容を無理に変換すると`ValueError`になります。たとえば`int("12.5")`は失敗します。小数を表す文字列なら、まず`float("12.5")`とします。その後で整数化する場合は、小数部分を失ってよいかを判断しなければなりません。

`bool()`にも注意が必要です。`bool("False")`は、文字の意味を読んで偽にするのではなく、空ではない文字列なので`True`になります。外部データの`"True"`や`"False"`は、内容を確認して明示的に変換します。

### 正しく実行できても、数値として妥当か確認する

0で割ると`ZeroDivisionError`になります。登録者0人の修了率や、修了者0人の1人当たり費用は、そのまま割り算をせず、後の条件分岐で処理方法を決めます。

`float`は多くの小数を2進数の近似として保存するため、`0.1 + 0.2`が`0.30000000000000004`と表示されることがあります。報告では`round()`で表示桁を整えられますが、丸めは元データの誤りを直す機能ではありません。何桁に丸めたかを明確にします。

**確認:** 境界や例外的な入力を一つ選び、期待する結果を説明できますか。

## 統合練習：章末課題へつながる軽い予行演習

**章末課題との接続：**

蓄電池の充電率を題材に、整数、浮動小数点数、文字列、真偽値を区別します。

### 作るもの

容量48単位に37単位が蓄えられています。割合を小数第1位まで表示し、75%以上かも表示してください。

### 完成条件

- 二つの量は整数、割合は浮動小数点数にします。

- 蓄電量÷容量×100で計算します。

- 丸め前の割合を75と比較します。

### 解答への手引き

1.  分子と分母を逆にしません。

2.  表示時だけ`:.1f`を使います。

3.  比較結果は真偽値です。

**まず自分で作り、実行結果を確認してから模範解答を開いてください。**

> [!ANSWER]
> **模範解答と解説**
>
> ```
> capacity = 48
> stored = 37
> rate = stored / capacity * 100
> print(f"CHARGE: {rate:.1f}%")
> print("READY:", rate >= 75)
> ```
>
> **代表的な確認結果**
>
>     CHARGE: 77.1%
>     READY: True
>
> 件数、計算した割合、しきい値判定は、それぞれ異なる型と意味を持ちます。

### 値を変えて再確認する

蓄電量を36、35へ変え、各実行前に割合と真偽値を予想してください。
