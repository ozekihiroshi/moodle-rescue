# 三つの実務課題から一つを選ぶ

三課題は同じpandas技能を使いますが、扱う問題と判断根拠は異なります。

| 選択 | 問題 | 発見 |
|---|---|---|
| 3.5A 学校給食 | 追加配送する学校を選ぶ | 不良データを除くと優先校が変わる |
| 3.5B 公共バス | 改善調査する路線を選ぶ | 平均遅延と乗客影響では優先路線が変わる |
| 3.5C 地域給水 | 現地点検する施設を選ぶ | 故障センサーと継続停止を区別する |

一つを完成すれば必須条件を満たします。余力があれば二つ目、三つ目へ進み、同じ処理を別のデータ意味へ転用してください。どの選択でも、第1段階の原資料確認プログラムと、第2段階の本番処理プログラムの二つを提出します。

## 選んだ課題を完成させる

選んだ課題の仕様を読み、Python Labで二つのプログラムを完成させます。自分で出力を確認し、それぞれの自動確認に合格したら、**今学習している対応版コースの該当する提出課題**へ二つのファイルをアップロードしてください。

## 第3章の選択課題を完了する

提出画面で提出済みの状態とファイルを確認したら、このページへ戻り、ページ上部の「完了マークする」を押します。読むだけで完了にはしません。

- A・B・Cのうち一つを完成させ、二つの確認プログラムに合格した。
- その課題へ二つのプログラムを提出し、提出状態を確認した。

この共通の完了確認は自己確認です。提出や採点を自動判定するものではありません。個々の課題の提出・採点記録は、それぞれの提出画面に残ります。

選ばなかった課題は追加練習です。取り組まなくても、この共通確認を終えれば選択課題の進捗は完了です。後から別の課題にも取り組めます。
