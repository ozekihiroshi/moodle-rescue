## 復習：入力から表示までつなぐ

`input()`で受け取った個数が`"3"`、単価が120円なら、合計を`TOTAL: 360`と表示するにはどうしますか。ここでは整数を入力するものとします。

> [!ANSWER]
> ```python
> count = int(input("Count: "))
> total = count * 120
> print(f"TOTAL: {total}")
> ```
>
> 入力直後は文字列です。計算する前に`int()`で整数へ変換し、f文字列で表示します。
