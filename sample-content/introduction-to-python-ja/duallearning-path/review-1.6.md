## 復習：一回ごとの状態を追う

次のループで、`total`がどう変わるかを一回ずつ書き出します。最後の値だけでなく、`range(1, 4)`がどの値を作るかも説明してください。

```python
total = 0
for number in range(1, 4):
    total = total + number
print(total)
```

> [!ANSWER]
> `number`は1、2、3です。`total`は0から1、3、6へ変わり、最後に`6`が表示されます。終了値4は含みません。合計を0にする行をループ内へ移すと、それまでの合計が毎回失われます。
