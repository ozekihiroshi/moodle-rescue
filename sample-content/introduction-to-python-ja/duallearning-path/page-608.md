## 1.6.1 forとrangeで既知の値を繰り返し処理する

### for文は、値の並びから一つずつ取り出す

`for attendance in weekly_attendance:`では、リストの各値が順に`attendance`へ入り、字下げされた処理を実行します。ループ変数は現在処理している値を表す一時的な名前です。ループ外の行は、すべての反復が終わってから一度だけ実行されます。

    weekly_attendance = [28, 31, 32, 34]
    for attendance in weekly_attendance:
        print("今週の出席者数:", attendance)
    print("処理完了")

### range()は開始を含み、終了を含まない

`range(start, stop, step)`は整数の並びを作ります。`range(1, 5)`は1、2、3、4で、5を含みません。`range(4)`は0から3です。期待する最初の値、最後の値、反復回数を先に書くと、一回多い・一回少ないという境界エラーを見つけやすくなります。

    print(list(range(1, 5)))
    for week in range(1, 5):
        print(f"第{week}週")
    print(list(range(10, 4, -2)))

## 1.6.2 合計と条件付き件数を作る

### アキュムレータはループの外で初期化し、内側で更新する

合計のように反復をまたいで残す値をアキュムレータと呼びます。合計は通常0から始め、各反復で現在の値を加えます。初期化をループ内へ置くと毎回0へ戻り、最後の値しか残りません。

    weekly_attendance = [28, 31, 32, 34]
    total = 0
    for attendance in weekly_attendance:
        total += attendance
        print("途中の合計:", total)
    print("合計:", total)
    print("平均:", total / len(weekly_attendance))

`sum()`で合計を求めることもできますが、明示的なループを追跡すると、後で条件付き集計や複数の状態を同時に更新する仕組みが理解できます。目的が単純な合計だけなら、実務では読みやすい`sum()`を選べます。

### カウンタは、条件に一致したときだけ1増やす

件数を数える変数も0から始めます。合計とカウンタは似ていますが、合計は値を加え、カウンタは一件につき1を加えます。

    weeks_at_least_30 = 0
    for attendance in [28, 31, 32, 34]:
        if attendance >= 30:
            weeks_at_least_30 += 1
    print(weeks_at_least_30)

## 1.6.3 最大・最小などの値と位置を追跡する

### 最大値は実データから初期化する

最大値を0から始めると、すべての値が負の場合に、データに存在しない0を最大値として返します。空でないことが分かっているなら最初の要素から始めます。空データの可能性があるなら、先に分岐して「データなし」を明示します。

    weekly_change = [-4, -2, -7, -3]
    if weekly_change:
        largest = weekly_change[0]
        for change in weekly_change[1:]:
            if change > largest:
                largest = change
        print("最大値:", largest)
    else:
        print("データなし")

### enumerate()は番号と値を同時に取り出す

人が読む週番号と値の両方が必要なら、手作業でカウンタを更新するより`enumerate()`が適します。`start=1`を指定すると、第1週から始められます。

    weekly_attendance = [28, 31, 32, 34]
    for week, attendance in enumerate(weekly_attendance, start=1):
        print(f"第{week}週: {attendance}人")

## 1.6.4 一回の処理またはループ全体を制御する

### continueは今回の残りを飛ばし、breakはループ全体を止める

`continue`は現在の反復の残りを飛ばして次の値へ進みます。`break`は残りの値を処理せずにループを終了します。通常処理の途中へ多用すると流れが分かりにくくなるため、欠損値を飛ばす、重大な無効値で停止する、といった理由を明確にします。

    readings = [28, None, 31, -1, 34]
    for reading in readings:
        if reading is None:
            continue
        if reading < 0:
            print("無効値を検出。停止します")
            break
        print("有効値:", reading)

## 1.6.5 条件が変わるまでwhileで繰り返す

### while文は、条件がTrueである間繰り返す

値の並びではなく、終了条件によって反復を決める場合は`while`を使います。条件に使う状態をループ内で終了へ近づけなければ、無限ループになります。実行が終わらない場合はNotebookの停止操作で中断し、条件と更新を確認します。

    remaining = 3
    while remaining > 0:
        print("残り:", remaining)
        remaining -= 1
    print("完了")

### 処理対象が分かっているならfor、終了条件で続けるならwhile

リストなどの反復可能な値を処理するならforが自然です。「成功するまで再試行する」「残数が0になるまで処理する」ならwhileが自然です。既知のリストを添字とwhileで処理すると、添字の初期化、境界、更新を自分で管理する必要があり、誤りが増えます。

## 1.6.6 0回の繰り返しと空の入力を扱う

### 空データでは、ループは一度も実行されない

空のリストに対するfor文は0回で正常終了します。合計は0のままですが、平均を`total / len(values)`で求めると0除算になります。ループ後に件数を確認し、平均が存在しないことを明示します。

    values = []
    total = 0
    for value in values:
        total += value
    if values:
        print(total / len(values))
    else:
        print("データなし")
