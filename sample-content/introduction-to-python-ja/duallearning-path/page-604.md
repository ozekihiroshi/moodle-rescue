## 導入

**値を計算したら、次はその値に応じて処理を選ぶ**

ここまでに、プログラムは値を作り、変数へ保存し、文字列や数値へ変換して、人に伝わる形で表示できるようになりました。しかし実務では、すべての値を同じように扱うわけではありません。修了率が低いセンターには支援を提案し、順調なセンターには通常の報告を作る、といった選択が必要です。Pythonでは、この選択を`if`文で表します。

## 1.5.1 ブール値を生む比較条件を作る

### 条件式はTrueまたはFalseという値を作る

`score >= 50`のような比較式を実行すると、結果は真偽値`bool`の`True`または`False`になります。`=`は右側の値を名前へ代入し、`==`は二つの値が等しいかを比較します。この違いは小さく見えますが、条件のバグを避けるための基本です。

    score = 68
    print(score >= 50)
    print(score == 68)
    print(score != 68)
    print(type(score >= 50))

| 演算子      | 判定                |
|-------------|---------------------|
| `==` / `!=` | 等しい / 等しくない |
| `<` / `<=`  | より小さい / 以下   |
| `>` / `>=`  | より大きい / 以上   |

**確認:** この項目の中心となる値・処理・結果を、自分の言葉で区別して説明できますか。

## 1.5.2 ifとelseで二つの処理から選ぶ

### if文は条件がTrueのときだけ字下げされた処理を実行する

`if 条件式:`の末尾にはコロンが必要です。次の行を字下げすると、その行がif文に属することを表します。Pythonの字下げは見た目だけではなく、プログラムの構造そのものです。

    score = 68
    if score >= 50:
        print("合格")
    print("判定完了")

68では条件がTrueなので二行とも表示されます。42なら`合格`は表示されませんが、字下げされていない`判定完了`は表示されます。どの行が条件の内側にあるかを意識して読みます。

### elseを加えると、二つの処理から必ず一つを選べる

`else`は直前の条件がFalseだった場合を受け持ちます。一回の判定でif側とelse側の両方が実行されることはありません。

    score = 42
    if score >= 50:
        result = "合格"
    else:
        result = "要復習"
    print(result)

## 1.5.3 複数候補と独立した処理を区別する

### elifは複数の候補を上から調べ、最初の一つだけを選ぶ

結果が三つ以上なら`elif`を使います。Pythonは上から条件を調べ、最初にTrueとなった分岐を実行すると残りを調べません。そのため、条件が重なる場合は、より限定的な条件を先に置きます。

    score = 85
    if score >= 90:
        grade = "優秀"
    elif score >= 70:
        grade = "合格"
    elif score >= 50:
        grade = "条件付き合格"
    else:
        grade = "要復習"
    print(grade)

もし`score >= 50`を最初に置くと、85もそこで一致し、上位の区分へ到達できません。エラーにならずに動くコードでも、業務ルールを誤って実装することがあります。

### 独立したif文は、条件がTrueならそれぞれ実行する

二つの独立した`if`は、両方がTrueなら両方を実行します。一方、`if / elif / else`は候補から一つだけを選びます。「合格なら通知し、上位成績なら追加の表彰もする」なら独立したif文が適します。「成績区分を一つ決める」なら一連の分岐が適します。

    score = 80
    if score >= 50:
        print("合格通知")
    if score >= 70:
        print("上位成績の表彰")

## 1.5.4 ブール論理で条件を組み合わせる

### and・or・notで複数の判定を組み合わせる

`and`は両方がTrue、`or`は少なくとも一方がTrueのときTrueになります。`not`は真偽を反転します。長い条件を一行へ詰め込まず、説明的な名前へ分けると、途中結果を表示して確認できます。

    registered = 35
    completion_rate = 72
    has_enough_learners = registered >= 30
    rate_needs_support = completion_rate < 75
    priority = has_enough_learners and rate_needs_support
    print(has_enough_learners, rate_needs_support, priority)

比較演算は`not`より先に評価され、次に`and`、最後に`or`が評価されます。ただし、優先順位を暗記して読ませるより、`(registered >= 30) and (completion_rate < 75)`のように括弧と名前で意図を示す方が安全です。

## 1.5.5 値の範囲を検証し、境界をテストする

### 境界値は、直前・一致・直後を実行する

`>= 50`は50を含み、`> 50`は含みません。しきい値75と85で区分するなら、74.9、75、84.9、85のように各境界の両側を試します。Pythonでは`0 <= score <= 100`のように、範囲を連鎖比較として書けます。

    rate = 75
    if rate < 75:
        status = "重点支援"
    elif rate < 85:
        status = "経過観察"
    else:
        status = "順調"
    print(status)

### 通常の分類より先に、入力値が妥当か確認する

点数-5を単に「要復習」へ分類すると、コードは動いても意味は誤っています。まず許される範囲を確認し、その後で通常の分類を行います。

    score = -5
    if not 0 <= score <= 100:
        result = "無効な点数"
    elif score >= 50:
        result = "合格"
    else:
        result = "要復習"
    print(result)

## 1.5.6 短絡評価を安全確認に使う

### 短絡評価は、結果が決まった後の式を評価しない

`and`は左側がFalseなら右側を評価せず、`or`は左側がTrueなら右側を評価しません。次の例では登録者数が0なので割り算を実行せず、ゼロ除算を避けます。ただし、条件式の右側に更新処理などの副作用を隠すと読みにくくなるため、判定は判定として書きます。

    registered = 0
    completed = 0
    if registered > 0 and completed / registered >= 0.75:
        status = "順調"
    else:
        status = "確認が必要"
    print(status)

**確認:** 境界や例外的な入力を一つ選び、期待する結果を説明できますか。

### 完成条件

- 一つの`if/elif/else`連鎖を使います。

- 2と10の直前、境界上、直後を試します。

1.  例外、狭い範囲、広い範囲の順に判定します。

2.  `weight < 2`は2を含みません。
