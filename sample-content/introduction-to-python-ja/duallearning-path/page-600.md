## 1.4.1 文字列を作り、調べ、変換する

### 引用符で文字列の範囲を示す

一重引用符と二重引用符は、どちらも文字列を作ります。内容に二重引用符を含めるなら外側に一重引用符を使うなど、読みやすい方を選べます。改行は`\n`、タブは`\t`、バックスラッシュ自体は`\`と書きます。

    course = "Python入門"
    message = '講師は「実行して確認」と言いました。'
    print(course)
    print(message)
    print("1行目\n2行目")

閉じ引用符を忘れるとPythonは文字列の終わりを判断できず、通常は`SyntaxError`になります。引用符の種類とエスケープは、文字列の内容とPythonの文法を区別するためにあります。

### 文字列は、0から位置を数える文字の並び

文字列の各文字には位置があります。最初の文字は0番、次は1番です。負の位置は末尾から数え、`-1`は最後の文字を表します。

    centre = "North Centre"
    print(centre[0])
    print(centre[-1])
    print(centre[0:5])
    print(len(centre))

`centre[0:5]`のようなスライスは、開始位置を含み終了位置を含みません。そのため0番から4番までの`North`になります。`len()`は文字数を返します。範囲外の位置を一文字として読むと`IndexError`になりますが、スライスは利用できる範囲で結果を返します。

### 文字列は変更不能なので、処理結果は新しい値になる

文字列の一文字だけを`centre[0] = "n"`のように置き換えることはできません。文字列は変更不能です。代わりに、整えた新しい文字列を作り、必要なら名前へ再代入します。

    raw_name = "  North Centre  "
    clean_name = raw_name.strip()
    print(clean_name)
    print(clean_name.lower())
    print(clean_name.upper())
    print(clean_name.replace("Centre", "Learning Centre"))
    print("元の値:", raw_name)

`strip()`は前後の空白、`lower()`と`upper()`は大文字・小文字、`replace()`は指定した部分を置き換えた新しい文字列を返します。元の`raw_name`は変化しません。この性質は、データクリーニングで元データと処理後データを区別するときにも役立ちます。

## 1.4.2 型を合わせて文字列と値を組み合わせる

### 連結するときは、型を揃える

文字列同士の`+`は連結、文字列と整数の直接加算は`TypeError`になります。数値を文字列へ連結するなら`str()`で意図を明示します。`*`は文字列を指定回数繰り返すので、区切り線などを作れます。

    completed = 29
    print("修了者: " + str(completed))
    print("-" * 20)

## 1.4.3 入力を受け取り、計算用の型へ変換する

### input()は必ず文字列を返す

`input()`は画面に問いを表示し、利用者が入力してEnterを押すまで待ちます。数字の36を入力しても、戻り値は文字列`"36"`です。計算する前に`int()`または`float()`で変換します。

    registered_text = input("登録者数: ")
    registered = int(registered_text)
    print(registered + 4)

Notebookでこのセルを実行すると入力待ちになります。セル左側が`[*]`のままなら、入力欄へ値を入れてEnterを押します。自動実行用Notebookでは停止を避けるため、この対話部分をコメントにし、同じ文字列を代入した例も用意しています。入力が空、または数字以外なら変換時に`ValueError`になるため、条件分岐と例外を学んだ後に安全な入力処理へ発展させます。

## 1.4.4 意味の分かる書式付き出力を作る

### f文字列で、説明と値を書式付きで組み合わせる

文字列の先頭に`f`を付けると、波括弧の中に名前や式を書けます。`.1f`は小数第1位、`.2f`は小数第2位、`,`は桁区切りを指定します。

    centre = "North Centre"
    registered = 36
    completed = 29
    rate = completed / registered * 100
    cost = 12345.5
    print(f"{centre}: {completed}/{registered}人、修了率 {rate:.1f}%")
    print(f"教材費: {cost:,.2f}")

書式は表示の形を整えるもので、変数`rate`や`cost`の元の値を変更しません。計算用の値と、人に見せる表現を分けて考えます。

## 1.4.5 単純な区切り文字付きテキストを読む

### 区切られた文字列を分ける

`split()`は区切り文字で文字列を分け、複数の文字列をリストとして返します。たとえば`"North,36,29"`をカンマで分けると、名称と二つの人数を取り出せます。リスト自体は後の章で体系的に学びます。

    record = "North,36,29"
    parts = record.split(",")
    centre = parts[0]
    registered = int(parts[1])
    completed = int(parts[2])
    print(f"{centre}: {completed}/{registered}人")

2.  整数には`int()`を使います。

3.  結果は一つのf文字列で表示します。
