## 2.1.1 リストで順序のある値を保持し、変更する

### リストは順序を持ち、内容を変更できる

リストは角括弧で作ります。文字列と同じく添字は0から始まり、負の添字は末尾から数え、スライスは終了位置を含みません。`len()`は要素数、`in`は値が含まれるかを返します。Pythonは異なる型も同じリストへ入れられますが、実務では同じ意味の値をそろえる方が安全です。

    attendance = [28, 31, 30, 33]
    print(attendance[0])
    print(attendance[-1])
    print(attendance[1:3])
    print(len(attendance))
    print(31 in attendance)

### リストの変更には、位置の代入と変更メソッドを使う

添字への代入は既存要素を置き換えます。`append()`は一つ、`extend()`は複数、`insert()`は指定位置へ追加します。`remove()`は最初に一致した値、`pop()`は位置の値を取り除いて返します。

    attendance = [28, 31, 30]
    attendance[0] = 29
    attendance.append(33)
    attendance.extend([32, 34])
    removed = attendance.pop()
    print(attendance)
    print("取り出した値:", removed)

`append()`など多くの変更メソッドは、既存のリスト自身を変更し、戻り値は`None`です。`attendance = attendance.append(33)`と書くと、名前がNoneを指してしまう典型的な誤りになります。

### 代入はリストを複製せず、同じオブジェクトを共有する

`shared = original`では、二つの名前が同じリストを参照します。一方から追加すると両方から見えます。独立した浅いコピーには`copy()`または全体スライスを使います。

    original = [28, 31, 30]
    shared = original
    separate = original.copy()
    shared.append(33)
    print("original:", original)
    print("shared:", shared)
    print("separate:", separate)

浅いコピーは外側のリストだけを複製します。内側に別のリストや辞書がある場合、その内側のオブジェクトは共有されます。入れ子構造を変更するときは、どこまで独立させる必要があるかを確認します。

## 2.1.2 タプルで固定された順序付き値を表す

### タプルは順序を持つが、作成後に要素を置き換えられない

タプルは丸括弧で作り、添字やループで読めます。年と月、座標など、固定された一組として扱い、途中で要素を変更させたくない値に向きます。要素数に合わせて複数の名前へ展開することもできます。

    report_period = (2026, 8)
    year, month = report_period
    print(year, month)
    # report_period[0] = 2027  # TypeError

## 2.1.3 辞書で名前付きフィールドを表す

### 辞書はキーによって各値の意味を表す

辞書は`キー: 値`の組を波括弧で作ります。数値の位置ではなく、`centre[\"registered\"]`のようなキーで読みます。キーは一つの辞書内で一意で、同じキーへ代入すると値を更新し、新しいキーへ代入すると項目を追加します。

    centre = {
        "name": "North Learning Centre",
        "district": "North",
        "registered": 40,
        "completed": 32,
    }
    centre["registered"] = 42
    centre["phone"] = "000-000"
    print(centre)

### 存在しないキーをどう扱うかは、項目の意味で決める

角括弧で存在しないキーを読むと`KeyError`になります。電話番号のような任意項目なら`get(\"phone\", \"未登録\")`で既定値を返せます。しかし登録者数のような必須項目にgetを使って0を補うと、欠落と本当の0を区別できません。`in`で存在を確認し、必須項目の欠落は無効データとして扱います。

    centre = {"name": "North", "registered": 40}
    print(centre.get("phone", "未登録"))
    print("completed" in centre)

### 辞書を反復するときは、必要な部分を選ぶ

辞書を直接for文へ渡すとキーを反復します。`keys()`もキー、`values()`は値、`items()`はキーと値の組を返します。

    centre = {"registered": 40, "attended": 34, "completed": 32}
    for field, value in centre.items():
        print(field, value)

## 2.1.4 辞書のリストで複数レコードを表す

### リストの中に辞書を置くと、複数のレコードになる

一つの辞書を一件のレコード、各キーを項目名として扱います。同じキー構成の辞書をリストへ並べると、小さな表のようなデータになります。これは後でCSVをDataFrameとして扱うための橋です。

    centres = [
        {"name": "North", "district": "A", "registered": 40, "completed": 32},
        {"name": "South", "district": "B", "registered": 35, "completed": 24},
    ]
    for centre in centres:
        rate = centre["completed"] / centre["registered"] * 100
        print(f"{centre['name']}: {rate:.1f}%")

## 2.1.5 集合で重複のない所属を表す

### 集合は重複のない所属と集合演算を表す

集合は値の順序や重複ではなく、「含まれるか」を扱います。和集合`|`、積集合`&`、差集合`-`を使うと、提供コースと希望コースのようなカテゴリを比較できます。集合の表示順には依存しません。空集合は`set()`で作ります。

    offered = {"Python", "Data", "Office"}
    requested = {"Python", "Web", "Data"}
    print("共通:", offered & requested)
    print("未提供:", requested - offered)
    print("すべて:", offered | requested)

| 構造  | 順序             | 変更 | 主な用途           |
|-------|------------------|------|--------------------|
| list  | あり             | 可   | 同じ意味の値の並び |
| tuple | あり             | 不可 | 固定された組       |
| dict  | 挿入順を保持     | 可   | 名前付き項目       |
| set   | 順序に依存しない | 可   | 重複のない所属     |

## 2.1.6 備品台帳のレコードを検索・追加・更新・削除する

### IDで一件を探し、該当なしを区別する

位置ではなく一意なIDを照合します。結果を最初は`None`とし、一致した辞書を保存して`break`します。最後まで見つからない`None`は「該当なし」という通常の検索結果です。

    found = None
    for book in books:
        if book["id"] == target_id:
            found = book
            break

### 一つの集合で追加・参照・更新・削除する

追加前にID集合で重複を確認します。検索結果の辞書はリストに保存された辞書そのものなので、項目を変更するとレコードも変わります。削除は`enumerate()`で位置を得て一度だけ`pop()`し、残る順序を保ちます。これがCRUDです。

## 統合練習：章末課題へつながる軽い予行演習

**章末課題との接続：**

図書管理プロジェクトの前に、別の集合である小型備品台帳をモデル化します。

### 作るもの

プロジェクターE01、カメラE02、スピーカーE03のレコードを作り、一つのリストへ保存します。E02を探して貸出不可へ変え、利用可能数を数えてください。

### 完成条件

- 各レコードは`id`、`name`、真偽値`available`を持つ辞書です。

- 台帳はレコードのリストです。

- 固定位置ではなくIDで探します。

### 解答への手引き

1.  3つの辞書リテラルから始めます。

2.  リストを回り、`item['id']`を比較します。

3.  `available`が真のレコードを数えます。

**まず自分で作り、実行結果を確認してから模範解答を開いてください。**

> [!ANSWER]
> **模範解答と解説**
>
> ```
> equipment = [
