## 1.7 小プロジェクト：週間サポート報告

### この課題ですること

1.  Python Labで`weekly_support.py`のTODOを完成させます。
2.  下のサンプル日報をキーボードから入力し、結果を自分で確認します。
3.  `check_weekly_support.py`を実行し、8項目を確認します。
4.  `ALL TESTS PASSED`になった`weekly_support.py`だけを提出します。

### 課題の状況

学習センターの担当者は、毎日の業務終了時に「受け付けた問い合わせ件数」と「その日のうちに解決した件数」を日報へ記録しています。週末には、手元の日報を見ながら月曜日から金曜日までの数字をプログラムへ入力します。プログラムは5日分を集計し、週間報告を画面に表示します。

担当者は日報の数字を順番に入力します。プログラムは、その後の集計、解決率の計算、対応状況の判定、最繁忙日の特定を自動化します。

### 入力方法と動作確認用のサンプル日報

次の表はCSVファイルでも、プログラム内へ直接記述するデータでもありません。完成したプログラムを確認するための架空の日報です。`weekly_support.py`を実行してから、表を見ながら上から順番に入力します。実際には毎週異なる数字を入力できるプログラムを作ります。

| 曜日      | 問い合わせ件数 | 解決件数 |
|-----------|----------------|----------|
| Monday    | 12             | 10       |
| Tuesday   | 18             | 16       |
| Wednesday | 15             | 15       |
| Thursday  | 20             | 17       |
| Friday    | 10             | 9        |

例えば、`Monday received:`には`12`、続く`Monday resolved:`には`10`を入力します。同じ操作をFridayまで続けます。

実務ではCSVや表計算シートから読み込むこともできますが、まだファイル入出力を学んでいないため、今回は`input()`と繰り返し処理を使って手入力します。ファイルの読み込みは後の課題で扱います。

### 作成するプログラム

5日分の入力を受け取り、次の項目を計算して表示します。

- 問い合わせ合計
- 解決合計
- 未解決件数
- 解決率
- 対応状況
- 最も問い合わせが多かった曜日

**実装上の約束：**この課題では繰り返し処理を練習するため、月曜日から金曜日までの入力を一つの`for`ループで処理します。同じ入力コードを5回繰り返して書かないでください。

| 条件                 | 仕様                                               |
|----------------------|----------------------------------------------------|
| 未解決件数           | 問い合わせ合計 − 解決合計                          |
| 解決率               | 解決合計 ÷ 問い合わせ合計 × 100。小数第1位まで表示 |
| 解決率90%以上        | `ON TRACK`                                         |
| 解決率80%以上90%未満 | `REVIEW`                                           |
| 解決率80%未満        | `PRIORITY SUPPORT`                                 |
| 最繁忙日が同数       | 最初に現れた曜日                                   |

### 期待される出力

サンプル日報を入力した結果は次のとおりです。英大文字の項目名は確認プログラムが読み取るため変更しません。

    WEEKLY SUPPORT REPORT
    TOTAL RECEIVED: 75
    TOTAL RESOLVED: 67
    UNRESOLVED: 8
    RESOLUTION RATE: 89.3%
    STATUS: REVIEW
    BUSIEST DAY: Thursday

### 問い合わせ0件と不正データ

- 5日間の問い合わせ合計が0件なら、解決率は`N/A`、状態は`NO REQUESTS`、最繁忙日は`NONE`とします。
- 負の件数、または解決件数が問い合わせ件数を超える値は不正です。
- 不正な値があってもFridayまで入力を続けます。入力後は見出し、合計、解決率、状態、最繁忙日を表示せず、`RESULT: INVALID`だけを表示します。
- この課題では整数が入力されるものとし、文字や小数の例外処理は後で扱います。

### 使用するPython

変数、整数、文字列、`input()`、`int()`、`print()`、f文字列、算術・比較・論理演算子、`if / elif / else`、`for`、`range()`だけで完成できます。関数、リスト、辞書、クラス、ファイル入出力、pandasは必要ありません。

> [!ANSWER]
> **実装へのヒント**
>
> 1.  二つの週間合計を、一日の入力ごとにどう更新しますか。
> 2.  不正な値があったことを、入力終了までどの変数へ記録しますか。
> 3.  最も多い件数と曜日をどう保持しますか。同数で最初の曜日を残す比較は何ですか。
> 4.  問い合わせ合計0件で割り算を避けるには、どの処理を先に判定しますか。
> 5.  80%と90%を正しく区分するには、条件をどの順序で書きますか。
>
> Python Labの`weekly_support.py`には入力の枠とTODOがあります。TODOを完成させ、最後の`PROGRAM INCOMPLETE`を削除します。

### 確認手順

#### 1. 自分で確認する

`weekly_support.py`を実行し、サンプル日報の10個の値を入力します。「期待される出力」と一致することを確認します。

Python Labのターミナルから実行する場合：

    python projects/weekly-support/weekly_support.py

#### 2. 確認プログラムを実行する

    python projects/weekly-support/check_weekly_support.py

確認プログラムは変更しません。通常の1週間、80%ちょうど、90%ちょうど、80%未満、最繁忙日の同率、問い合わせ0件、解決件数超過、負の件数の8項目を確認します。`NG`では期待値と実際の値を読み、`weekly_support.py`だけを修正します。
