## 3.2.1 問いを表示列と行条件へ分ける

### 必要列を検査し、部分条件へ分ける

「2026年2月と3月について、登録者30人以上で出席率80%未満のセンター名を確認する」なら、表示する列、月の所属条件、登録者数の下限、出席率の上限へ分解します。処理前に必要列と`df.columns`の差集合を取り、欠けた列を明示します。

    required = {"month", "centre_name", "registered", "attended"}
    missing = required - set(df.columns)
    if missing:
        raise KeyError(sorted(missing))

### 列名で必要な項目を選ぶ

`df[\"registered\"]`は一列のSeries、`df[[\"month\", \"registered\"]]`は複数列のDataFrameです。列名は完全一致で指定します。結果に必要な列と条件計算だけに必要な列を区別し、表示列を選びます。

## 3.2.2 locとilocで行・列を選ぶ

`loc[行条件, 列名]`はindexラベルと列名を使い、分析上の意味をコードへ残せます。`iloc[行位置, 列位置]`は0から始まる位置を使い、先頭行の確認などに向きます。indexラベルは常に0, 1, 2とは限らないため、ラベルと位置を混同してはいけません。

## 3.2.3 比較式をブールマスクにする

`df[\"registered\"] >= 30`は、元のindexと対応するブールSeriesを返します。`True`の行が条件に一致します。`mask.sum()`で該当件数を数え、抽出前後の件数とともに記録すると、条件の向きや境界の誤りを発見しやすくなります。

    large = df["registered"] >= 30
    print(large.head())
    print("該当件数:", int(large.sum()))
    result = df.loc[large, ["month", "centre_name", "registered"]]

## 3.2.4 ブール論理で複数条件を組み立てる

Pythonの単一の真偽値には`and`、`or`、`not`を使います。Seriesを行ごとに組み合わせるpandasでは`&`、`|`、`~`を使い、各比較を括弧で囲みます。Seriesへ`and`を使うと、Series全体を一つの真偽値へ決められずエラーになります。

    large = report["registered"] >= 30
    low_rate = report["attendance_rate"] < 80
    print("AND:", int((large & low_rate).sum()))
    print("OR:", int((large | low_rate).sum()))
    print("NOT large:", int((~large).sum()))

### AND・OR・NOTを件数で確かめる

ANDは両方を満たすため通常は狭くなり、ORはいずれかを満たすため通常は広くなります。NOTは真偽を反転します。ド・モルガンの法則により`~(A | B)`と`(~A) & (~B)`は同じです。ただし、業務上の意味が読みやすい形を選び、部分マスクの件数でも確認します。

**確認:** Seriesの条件でandではなく&を使う理由を、各行の判定という言葉を使って説明してください。

## 3.2.5 所属・範囲・欠損を条件に表す

複数候補のいずれかに一致するなら`isin()`、上下限を持つなら`between()`を使えます。`between()`は既定で両端を含みます。「以上」「以下」「未満」の違いを問題文と一致させます。

    months = report["month"].isin(["2026-02", "2026-03"])
    size = report["registered"].between(25, 35, inclusive="both")
    subset = report.loc[months & size]

### 欠損を条件から偶然落とさない

欠損値との大小比較は通常Falseになり、理由を示さないまま抽出から消えることがあります。値が必要なら`notna()`、欠損を調べるなら`isna()`を条件へ加え、件数を別に記録します。ここでは補完や削除をせず、3.3で扱う品質問題として保持します。

    known = report["attended"].notna()
    low_known = known & (report["attendance_rate"] < 80)
    print(int(low_known.sum()))
    print("欠損:", int(report["attended"].isna().sum()))

## 3.2.6 抽出し、並べ、件数を検証する

一つの長い式へ埋め込まず、月、規模、率、欠損の条件へ名前を付けると、それぞれの件数を確認できます。最後に`loc[最終マスク, 表示列]`で抽出し、必要なら`sort_values()`で再現可能な順序にします。結果には元件数、該当件数、条件を添えます。

### マスクと行をindexで対応させる

pandasはマスクを物理的な位置だけでなくindexラベルで対応させます。別のDataFrameから作ったマスクや、index変更前の古いマスクを流用すると、ずれやエラーの原因になります。原則として抽出対象と同じDataFrameからマスクを作ります。

**確認:** 最終結果だけでなく、どの件数を残すと条件の誤りを見つけやすいでしょうか。
