## 理解度チェック：考え方が自分のものになるまで練習する

これらは一度だけ受ける試験ではありません。理解できたことを確認し、思い違いに気づき、解説を読んで、もう一度試すための活動です。

1.  間違いを恐れず、10問すべてに答えます。
2.  送信後、間違えた選択肢のフィードバックをすべて読みます。
3.  つながる例題へ戻り、実行するか処理を追います。
4.  値または境界を一つ変更します。
5.  もう一度取り組みます。最高得点が記録されます。

### 進捗

- **90%以上：**合格です。おめでとうございます。
- **100%：**完全習得の目標です。
- **90%未満：**失敗ではなく、復習すべき内容を示す有用な根拠です。

誤答の一部は、よくある間違いを意図的に使っています。分子と分母の逆転、数値として文字列を使うこと、境界値の除外、ANDとORの混同、平均値と中央値の混同、グループ割合の誤った単純平均などです。
