## 学習の流れ

各レッスンは、授業前の準備と予想→本文を使った授業→Python Labで実行→授業後の復習→理解度チェックの順です。正解を予習で調べる必要はなく、予想と実行結果の違いを授業で確かめます。

章末課題は、入力・成果物・完成条件の確認→自分で実装→途中の結果を教師へ見せる→自動確認→このコースへ提出→教師の評定・コメント確認という流れです。第3章A/B/Cは一つ選択し、提出後に共通確認を完了します。他の課題は任意です。

各章に「質問と相談」があります。授業中は画面を教師へ見せ、授業外は単元番号、試したコード、結果をフォーラムへ残します。返信時間や授業日程は導入時に教師が案内してください。

Labの個人ファイルは自学自習版と共有します。別の練習ファイルが必要なら学習者が別名で保存します。Moodleの提出・評定・完了はコースごとに独立しています。直接提出スクリプトで旧コースへ送らず、指定されたファイルをダウンロードして今学習しているコースの課題へアップロードします。

## 原稿と再反映

- `units.json`：23単元ごとの予習・授業・復習の要点。
- `*-prepare.md`、`*-review.md`：予習と復習。本文・コード・模範解答・課題条件は隣の`duallearning-path`を共有原稿とします。
- `local-mapping.json`：検証サイトの複製元／先活動ID。別サイトで使用する設定ではありません。
- `scripts/build-python-guided-materials.py`：原稿生成。原稿を直接推敲した場合、再生成前に生成元へ変更を戻してください。
- `scripts/prepare-python-guided-course.php`：ローカル作業コピー作成。既存コースがある場合は上書きせず停止。
- `scripts/install-python-guided-chapter.php`：指定章を反映し、活動IDを保って案内を更新。
- `scripts/check-python-guided-chapter.php`：章別の本文コード・リンク・配置・クイズ・提出条件の検査。
- `scripts/finalize-python-guided-course.php`：23単元の配置を確認し、全章コースを表示。LessonMark連続表示順と質問先も検査。

作成時は章ごとに反映→検査を行い、新規のプラグイン不具合があればそこで停止します。授業日程・提出期限・教師の返信方針は実施者が決めるため、架空の日付は設定していません。

詳細な検証結果と公開前の残作業は[教師伴走版の検証記録](../../../docs/python-guided-markdown-progress.md)を参照してください。
