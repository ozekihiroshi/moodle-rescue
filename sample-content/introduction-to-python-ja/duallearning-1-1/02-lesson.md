先ほどの二行は、一行目が`7`、二行目が`3 + 4`と表示されます。Pythonは引用符の外にある数値を計算し、引用符の内側を文字として扱ったからです。この違いを手がかりに、短いプログラムを読みましょう。

このレッスンを終えると、命令・値・式・出力を見分け、実行順と計算順を予測し、変更後の結果を確かめられます。

## 1.1.1 値・式・出力を読み分ける

次のプログラムは、講座を1日3回、5日間開き、各回16人が参加できるときの規模を表示します。Labで実行する前に、表示される三行を予想してください。

```python
print("講座実施計画")
print(3 * 5)
print(3 * 5 * 16)
```

Pythonは通常、命令を上から順に実行します。`print(...)`は表示する命令、`3`・`5`・`16`は数値、`3 * 5`は計算して一つの値になる式です。画面には見出し、`15`、`240`の順で出ます。

| 読み取るもの | この例 | 役割 |
| --- | --- | --- |
| 命令 | `print(...)` | コンピュータに行わせる処理 |
| 値 | `3`、`5`、`16`、見出しの文字 | プログラムが扱うデータ |
| 式 | `3 * 5 * 16` | 評価されると一つの値になる計算 |
| 出力 | 表示された三行 | 処理の結果を画面へ示すもの |

式を評価することと、結果を表示することは別です。Notebookではセルの最後に`3 * 5`だけを書くと結果が見えますが、通常の`.py`ファイルはその式だけでは表示しません。表示したい結果には`print()`を使います。

引用符にも注意してください。`print(3 + 4)`は数の和`7`を表示し、`print("3 + 4")`は引用符の中の文字をそのまま表示します。型の名前や変換は1.3で詳しく扱います。今は数値と文字を読み分ければ十分です。

**小さな確認：** `print(2 * 6)`の中で値を作る部分と、画面に示す部分をそれぞれ指してください。

## 1.1.2 計算順序を明確にする

この単元では加算`+`、減算`-`、乗算`*`を使います。乗算は加減算より先に計算され、括弧の中はさらに先です。次の二行を予想してから実行してください。

```python
print(2 + 3 * 4)
print((2 + 3) * 4)
```

一行目は`14`、二行目は`20`です。括弧は計算順だけでなく意味も伝えます。定員40人から午前18人と午後12人を引いて未使用席を調べるなら、`40 - (18 + 12)`と書くと、参加者の合計を先に求める意図が見えます。

**小さな確認：** 定員50人で午前19人、午後21人なら、未使用席を表す式はどう書きますか。実行結果も確かめてください。

## 1.1.3 変更して、結果のつじつまを確かめる

次は午前・午後の参加枠、合計、未使用席を表示するプログラムです。五行を予想してから実行します。

```python
print("研修参加枠")
print("午前:", 18)
print("午後:", 12)
print("合計:", 18 + 12)
print("未使用席:", 40 - (18 + 12))
```

午前を20人に変更してください。元の`18`は三か所にあるため、一か所だけを直すと出力が矛盾します。コードが動くかだけでなく、`午前 + 午後 = 合計`、`合計 + 未使用席 = 定員`を確認します。1.2では、このような値に名前を付け、変更漏れを減らします。

## 1.1.4 統合練習：本の箱詰めを報告する

1箱に12冊入り、満杯の箱が4箱あります。次の四行を表示するコードを、何も見ずに先に作ってください。`48`を直接入力せず、Pythonに計算させます。

文字のラベルには引用符を使い、各行に`print()`を一つ置きます。コードを保存して実行し、自分の出力を上の四行と比べてください。
