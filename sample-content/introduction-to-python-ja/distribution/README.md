# Python日本語コース アルファ版 0.1.0-alpha.1

Moodleコース **Pythonによるデータ活用：AI時代の基礎**
（`PYAI-INTRO-JA`）を新しいサイトへ復元するための配布物です。
英語版`PYAI-INTRO`を正本とする公式日本語適応版で、形式上も独立した
Moodleコースです。

## ファイル

- `python-for-data-foundations-ai-era-ja-0.1.0-alpha.1.mbz` — コースバックアップ
- `manifest.json` — リリース、互換性、英語正本との関係、収録内容
- `SHA256SUMS` — 完全性確認用チェックサム
- `LICENSE.txt` — CC BY 4.0の表示

Moodle 5.2.2で作成し、利用者アカウント、受験履歴、提出履歴、修了履歴などの
利用者依存データを除外しています。

```sh
sh scripts/verify-python-sample-distribution-ja.sh
```

```text

```

## Moodleへの復元

1. **サイト管理 > コース > コースをリストアする**を開きます。
2. バージョン付き`.mbz`をアップロードし、新規コースとして復元します。
3. 公開状態、登録方法、修了条件、評定、提出課題を確認します。
4. 教師権限を持たないテスト受講者で、表示と学習経路を確認します。

Python Labの外部ツール活動を使う場合は、別途Python Labを構築し、サイト固有の
LTI 1.3登録を行います。署名鍵、クライアントシークレット、デプロイメント情報、
学習者Notebook領域はこの配布物に含みません。

## アルファ版の制限

Chapter 0からChapter 6までの学習経路を収録していますが、文章の推敲、
学習者による試行、アクセシビリティ確認、評価の最終調整は継続中です。
評価または管理された試行授業向けの版として扱ってください。
