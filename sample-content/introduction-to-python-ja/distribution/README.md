# 日本語版サンプルコース release 1.0.0

このディレクトリには、Moodleコース **Pythonによるデータ活用：AI時代の基礎**
（`PYAI-INTRO-JA`）を新しいサイトへ復元するための正式な配布物があります。
英語版 `PYAI-INTRO` 1.0.0を正とする公式日本語適応版であり、逐語訳ではなく、
日本語で学ぶ人に合わせて説明や指導表現を作り直しています。

## ファイル

- `python-for-data-foundations-ai-era-ja-1.0.0.mbz` — Moodleコースバックアップ
- `manifest.json` — リリース、互換性、英語正本との関係を示すメタデータ
- `SHA256SUMS` — 完全性確認用チェックサム
- `LICENSE.txt` — CC BY 4.0の通知と推奨表示

このバックアップはMoodle 5.2.2で作成され、学習者アカウント、受験履歴、
役割割当、修了履歴を含みません。復元先と同じMoodleバージョンで事前に
復元テストを行ってから受講者へ公開してください。

## 復元前の確認

リポジトリのルートからWSLで実行します。

```sh
sh scripts/verify-python-sample-distribution-ja.sh
```

期待されるSHA-256：

```text
a04b3800a47c0256eae99cdc48aaa52a4968e8754b45c454912f16cded482953
```

## Moodleへの復元

1. サイト管理者、またはコース復元権限を持つ利用者でログインします。
2. **サイト管理 > コース > コースをリストアする** を開きます。
3. `.mbz` ファイルをアップロードし、新しいコースとして復元します。
4. 教師用資料と模範解答が非表示のままであることを確認します。
5. 教師権限を持たないテスト受講者で表示と理解度チェックを確認します。

## Python LabとLTI 1.3

教材、課題、理解度チェックはバックアップに含まれますが、Python Lab
サービス自体とLTI 1.3の秘密情報は含まれません。復元先でPython Labを
構築し、LTI 1.3ツールを登録してください。署名鍵、クライアントシークレット、
デプロイメントID、非公開URL、学習者のNotebook領域を配布物へコピーしては
いけません。
