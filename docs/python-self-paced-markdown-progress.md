## 改修へ渡す所見：サブセクションを含む次教材順序

対象：`format_duallearning` 0.1.0-alpha4 (`2026091802`)、`classes/local/overview.php` の `collect_items()`。

`get_fast_modinfo(...)->get_cms()` の順番をそのまま使ってtargetsを作り、`first_incomplete()` が先頭の未完了活動を選ぶ。しかし、この順番は、章内に置かれたサブセクションの表示順をたどった順番とは一致しない。

既存の日本語版コース12、第1章で確認した結果：

| 種類 | 本文ページの順番 |
| --- | --- |
| 章内に配置された単元の順 | 1.1 → 1.2 → **1.3 → 1.4** → 1.5 → 1.6 → 1.7 |
| 現行collect_itemsが採用する順 | 1.1 → 1.2 → **1.5 → 1.6 → 1.7** → 1.3 → 1.4 |

1.1と1.2の本文を確認済みとするメモリ上の状態を作り、インストール済みプラグインの `first_incomplete()` に渡すと、1.3ではなく1.5が返る。実際の学習者の完了記録は変更していない。元コースはこの形式へ変更していないため、「元の公開コースの画面で現在誤案内されている」とは主張しない。既存の階層を保って新形式へ移す際に影響する不具合である。
