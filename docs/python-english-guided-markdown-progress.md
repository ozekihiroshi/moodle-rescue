## 学習の流れ

23単元を「予習 → 本文 → Python Lab → 復習 → 理解度チェック」の順に配置。予習は短い予想と環境確認、授業中は単元固有の比較・検証、復習は統合練習の再現または入力変更と解答照合とする。授業中に完成したものを作り直す必要はない。

予習・復習の完了は本人の確認であり教師の評定ではない。各章の質問フォーラムに単元番号・試したコード・出力を残し、教師の返信を確認できる。質問投稿自体は修了条件にしない。

第3章はA/B/Cから一つを提出し、共通確認を本人が完了する。選ばない二つは未完了必須課題としない。自動的に提出・評点からOR条件を判定する構成ではない。

Labのファイルは同じ利用者の自立学習版と共有するが、Moodleの提出・評定はこのコースで独立する。授業日時・締切は架空の日付を入れず、担当教師が設定する。

## ソースと再開

- `sample-content/introduction-to-python/duallearning-guided/`: 46ページの予習・復習Markdown、23単元の授業内容、ローカルID対応表。
- `scripts/build-python-english-guided-materials.py`: 英語案内と既存日本語版の複製・検査ツールの機械的な英語対応版を生成。
- `scripts/prepare-python-english-guided-course.php`: ユーザー情報なしの初回複製。既存コースを上書きしない。
- `scripts/run-python-english-guided-local.sh`: 既存の教師伴走版に章ごと反映し、検証に通った場合だけ次章へ進む。ローカルMoodle限定。
- `scripts/verify-python-english-path.php --guided`: 全章の件数、英語問題、リンク、順序。
- `scripts/check-python-path-submission-roundtrip.php --english-guided`: ローカル専用テストユーザーへの提出検証。異なる既存提出は上書きしない。

これらは現ローカル環境のID対応表を用いる開発ツールで、任意の本番サイトにそのまま実行する汎用インストーラーではない。
