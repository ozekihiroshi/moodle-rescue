## 検証の限界と運用前の確認

- 全230問をUIで再受験した、全32Notebookの全セルを新たに実行した、という報告ではない。コード・問題・Labの行先は検証済み自学自習版から変更せず、今回の差分である教師伴走導線と復元後の構成を重点確認した。
- 教師のコメント保存は標準API、受講者への表示は実ブラウザで検証。教師の全操作をブラウザでやり直したわけではない。
- 検証提出32〜39とテスト用コメントがユーザー5に存在する。実受講者の評価ではない。配布バックアップにはユーザー情報を含めない。
- 表示日時は検証ユーザーのタイムゾーンに従う。実授業の日時・締切は未設定。担当教師が日程と返信方針を案内する。
- 公開用バックアップ、英語対応版、日英照合、コミット・pushは今回実施していない。プラグイン自体も変更していない。
